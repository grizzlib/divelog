# Changelog

## 1.0.5 - 2026-08-22

- Added CSV export for the currently displayed Dive List.
- CSV export respects active search, sort, and filters.
- CSV export saves to the app documents directory.
- Export success message shows the saved file path.

## 1.0.4 - 2026-08-05

- Added date range filters to the Dive List screen.
- Added depth range filters to the Dive List screen.
- Date and depth filters work with existing search, sort, and structured filters.

## 1.0.3 - 2026-08-05

- Added structured filters to the Dive List screen.
- Added filters for activity type, gas mix, and tank type.
- Filters work with the existing search and sort options.

## 1.0.2 - 2026-07-03

- Added sort options to the Dive List screen.
- Added simple search to the Dive List screen.
- Search works with existing sort options.

## 1.0.1 - 2026-07-03

- Dashboard is now the home screen.
- Recent dives were added to the dashboard.
- Dashboard bottom padding was improved.
- Add Dive now suggests the next dive number while keeping the field editable.
